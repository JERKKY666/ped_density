# Pedestrian and Vehicle Density Control for FiveM

This ultra-lightweight FiveM script reduces the vehicle and pedestrian population around the map to approximately 20% and modifies NPC behavior during combat. Instead of NPCs fighting back when players shoot, civilians will now flee in fear, enhancing realism for roleplay servers.

## Features
- 🚗 Reduces vehicle traffic and pedestrian density to ~20%.
- 🏃‍♂️ Civilians flee when players shoot instead of fighting back.
- 🧠 Adjusts NPC relationship groups to prevent random hostility.
- ⚡ Optimized for extremely low resource usage (0.00ms idle).
- 🛠️ Compatible with any framework (ESX, QBCore, or standalone).
